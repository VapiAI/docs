Choose a voice with `voice.provider: "openai"` and `voice.voiceId`. GPT-Live supports 22 preset voices in Vapi. Use the dashboard's voice previews or the recordings below to compare them.

## Configure a voice

Set this object on your assistant:

```json
{
  "voice": {
    "provider": "openai",
    "voiceId": "bossa"
  }
}
```

Publish the updated assistant and start a new call to test the change. This integration does not expose an in-call voice change.

## Set the spoken language

A voice choice does not replace language instructions. Write the speaker prompt in the language you want the assistant to use, and test both its greeting and its responses.

For a Brazilian Portuguese assistant using Bossa or Tempo, this model fragment sets a clear language policy:

```json
{
  "speaker": {
    "instructions": "Você ajuda a pessoa a agendar um atendimento. Fale em português do Brasil, com respostas curtas e claras. Faça uma pergunta por vez. Encaminhe ao backend pedidos que precisem consultar dados ou usar ferramentas. Só confirme um agendamento depois de receber a confirmação do backend."
  }
}
```

Use the same language for `firstMessage`, such as “Olá! Como posso ajudar hoje?” Configure the reasoner's business rules and tools separately.

## Test pronunciation and speaking style

Include real task vocabulary in your tests: names, addresses, dates, and product terms. Add pronunciation guidance to the speaker prompt when needed, then evaluate the spoken result.

A preview is an example recording, not a promise that every response has identical pacing or expression. Compare voices using the same prompt and representative calls.

See OpenAI's [voice options](https://developers.openai.com/api/docs/guides/live-conversations#voice-options) for the source metadata and [language guidance](https://developers.openai.com/api/docs/guides/live-prompting#language-and-pronunciation) for prompting recommendations. Vapi's supported catalog is the list on this page; upstream custom-voice capabilities do not imply support in this integration.
