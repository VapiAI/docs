## Overview

Build a voice-powered documentation assistant step by step. Choose between using the Dashboard interface or programmatic APIs to suit your workflow.

You'll learn to:

- Index your docs with LlamaCloud
- Create an API Request tool for document retrieval
- Create an assistant with Claude Sonnet 4.6 and attach the tool
- Use the Web SDK to create a React voice widget
- Review completed calls and improve the quality of your assistant over time

## Prerequisites

- [Vapi account](https://dashboard.vapi.ai/) with a [private API key](/security-and-privacy/api-keys) for the server examples and a public API key for the Web SDK example
- [LlamaCloud account](https://cloud.llamaindex.ai/) on a Starter, Pro, or Enterprise plan, plus an API key
- A Vapi [Bearer Token custom credential](/server-url/server-authentication#standard-authorization-header) configured with your LlamaCloud API key, `Authorization` as the header name, and the Bearer prefix enabled
- Documentation files in a [format supported by LlamaCloud](https://developers.llamaindex.ai/llamaparse/general/supported_document_types/)

## Get started

<Steps>
  <Step title="Index your documentation">
    Create a searchable index with LlamaCloud Index v2:

    1. Create a directory and add the documentation files you want to search.
    2. Create an index that uses the directory as its source.
    3. Wait until the index status is `ready`, then copy the index ID. You use this ID when you configure the Vapi tool.

    Index v2 parses, chunks, embeds, and indexes the files automatically. LlamaCloud manages the chunking and embedding settings. For more details, see the [LlamaCloud Index getting started guide](https://developers.llamaindex.ai/llamaparse/cloud-index-v2/getting_started/).
  </Step>

  <Step title="Create the retrieval tool">
    Create an API Request tool that connects your assistant to your LlamaCloud index.

    <Tabs>
      <Tab title="Dashboard">
        1. Navigate to **Tools** in your [Vapi Dashboard](https://dashboard.vapi.ai/).
        2. Click **Create Tool**.
        3. Select **API Request** as the tool type.
        4. Under **Base Configuration**, enter:
           - **Tool Name**: `docsquery`
           - **Description**: `Search the documentation index for relevant information`
           - **Request URL**: `https://api.cloud.llamaindex.ai/api/v1/retrieval/retrieve`
           - **Request HTTP Method**: `POST`
        5. Under **Authorization**, select the Bearer Token custom credential that contains your LlamaCloud API key.
        6. Under **Request Body**, add a required String property named `query` with the description `The search query to find relevant documentation`.
        7. Under **Static Body Fields**, add a String field named `index_id` and set its value to your LlamaCloud index ID.
        8. Add a Number field named `top_k` and set its value to `5`.
        9. Select **Publish**, then copy the tool ID.
      </Tab>
      <Tab title="TypeScript (Server SDK)">
        ```typescript
        import { VapiClient } from "@vapi-ai/server-sdk";

        const vapi = new VapiClient({ token: "YOUR_VAPI_PRIVATE_API_KEY" });

        const tool = await vapi.tools.create({
          type: "apiRequest",
          name: "docsquery",
          description: "Search the documentation index for relevant information",
          method: "POST",
          url: "https://api.cloud.llamaindex.ai/api/v1/retrieval/retrieve",
          credentialId: "YOUR_LLAMACLOUD_CREDENTIAL_ID",
          parameters: [
            {
              key: "index_id",
              value: "YOUR_LLAMACLOUD_INDEX_ID"
            },
            {
              key: "top_k",
              value: 5
            }
          ],
          body: {
            type: "object",
            properties: {
              query: {
                type: "string",
                description: "The search query to find relevant documentation"
              }
            },
            required: ["query"]
          },
        });

        console.log(`Tool created with ID: ${tool.id}`);
        ```
      </Tab>
      <Tab title="Python (Server SDK)">
        ```python
        from vapi import JsonSchema, ToolParameter, Vapi
        from vapi.tools import CreateToolsRequest_ApiRequest

        client = Vapi(token="YOUR_VAPI_PRIVATE_API_KEY")

        tool = client.tools.create(
            request=CreateToolsRequest_ApiRequest(
                name="docsquery",
                description="Search the documentation index for relevant information",
                method="POST",
                url="https://api.cloud.llamaindex.ai/api/v1/retrieval/retrieve",
                credential_id="YOUR_LLAMACLOUD_CREDENTIAL_ID",
                parameters=[
                    ToolParameter(
                        key="index_id",
                        value="YOUR_LLAMACLOUD_INDEX_ID",
                    ),
                    ToolParameter(
                        key="top_k",
                        value=5,
                    ),
                ],
                body=JsonSchema(
                    type="object",
                    properties={
                        "query": JsonSchema(
                            type="string",
                            description="The search query to find relevant documentation",
                        ),
                    },
                    required=["query"],
                ),
            ),
        )

        print(f"Tool created with ID: {tool.id}")
        ```
      </Tab>
      <Tab title="cURL">
        ```bash
        curl --request POST \
          --url https://api.vapi.ai/tool \
          --header "Authorization: Bearer YOUR_VAPI_PRIVATE_API_KEY" \
          --header "Content-Type: application/json" \
          --data '{
            "type": "apiRequest",
            "name": "docsquery",
            "description": "Search the documentation index for relevant information",
            "method": "POST",
            "url": "https://api.cloud.llamaindex.ai/api/v1/retrieval/retrieve",
            "credentialId": "YOUR_LLAMACLOUD_CREDENTIAL_ID",
            "parameters": [
              {
                "key": "index_id",
                "value": "YOUR_LLAMACLOUD_INDEX_ID"
              },
              {
                "key": "top_k",
                "value": 5
              }
            ],
            "body": {
              "type": "object",
              "properties": {
                "query": {
                  "type": "string",
                  "description": "The search query to find relevant documentation"
                }
              },
              "required": ["query"]
            }
          }'
        ```
      </Tab>
    </Tabs>

    Replace `YOUR_LLAMACLOUD_INDEX_ID` and `YOUR_LLAMACLOUD_CREDENTIAL_ID` with the values for your LlamaCloud index and saved Vapi credential. The `index_id` field identifies the index, and `top_k` limits each retrieval to five results. The model supplies `query` for each retrieval.

    LlamaCloud returns matches in `results`; the retrieved text is available in each result's `content` field.
  </Step>

  <Step title="Create an assistant with the tool">
    Create an assistant with the API Request tool attached.

    <Tabs>
      <Tab title="Dashboard">
        1. Navigate to **Assistants** in your [Vapi Dashboard](https://dashboard.vapi.ai/).
        2. Click **Create Assistant**.
        3. Configure the assistant:
           - **Name**: `Docs agent`
           - **Model**: Claude Sonnet 4.6 (Anthropic)
           - **Voice**: Elliot (Vapi)
           - **First Message**: `Hey I'm Harry, a support agent. How can I help you today? You can ask me questions about Vapi, how to get started, or our documentation.`
           - **System Prompt**: Use a helpful documentation assistant prompt with guidelines for using the docsquery tool
        4. Add the `docsquery` tool in the Tools section.
        5. Publish the assistant.
      </Tab>
      <Tab title="TypeScript (Server SDK)">
        ```typescript
        import { VapiClient } from "@vapi-ai/server-sdk";

        const vapi = new VapiClient({ token: "YOUR_VAPI_PRIVATE_API_KEY" });

        const systemPrompt = `You are a helpful documentation assistant. Use the docsquery tool to find relevant information when users ask questions about the documentation.

Guidelines:
- Always be helpful, friendly, and concise
- Provide accurate information based on the documentation
- When you don't know something, say so clearly
- Keep responses conversational for voice interaction
- Use the docsquery tool whenever users ask specific questions about features, setup, or implementation
- Summarize complex information in an easy-to-understand way
- Ask clarifying questions if the user's request is unclear
- Provide step-by-step guidance when explaining processes`;

        const assistant = await vapi.assistants.create({
          name: "Docs agent",
          model: {
            provider: "anthropic",
            model: "claude-sonnet-4-6",
            messages: [
              {
                role: "system",
                content: systemPrompt
              }
            ],
            toolIds: ["YOUR_TOOL_ID"]
          },
          voice: {
            provider: "vapi",
            voiceId: "Elliot"
          },
          transcriber: {
            provider: "deepgram",
            model: "nova-2",
            language: "en"
          },
          firstMessage: "Hey I'm Harry, a support agent. How can I help you today? You can ask me questions about Vapi, how to get started, or our documentation.",
          endCallMessage: "Goodbye.",
          backgroundSound: "off"
        });

        console.log(`Assistant created with ID: ${assistant.id}`);
        ```
      </Tab>
      <Tab title="Python (Server SDK)">
        ```python
        from vapi import (
            CreateAssistantDtoModel_Anthropic,
            CreateAssistantDtoTranscriber_Deepgram,
            CreateAssistantDtoVoice_Vapi,
            OpenAiMessage,
            Vapi,
        )

        client = Vapi(token="YOUR_VAPI_PRIVATE_API_KEY")

        system_prompt = """You are a helpful documentation assistant. Use the docsquery tool to find relevant information when users ask questions about the documentation.

Guidelines:
- Always be helpful, friendly, and concise
- Provide accurate information based on the documentation
- When you don't know something, say so clearly
- Keep responses conversational for voice interaction
- Use the docsquery tool whenever users ask specific questions about features, setup, or implementation
- Summarize complex information in an easy-to-understand way
- Ask clarifying questions if the user's request is unclear
- Provide step-by-step guidance when explaining processes"""

        assistant = client.assistants.create(
            name="Docs agent",
            model=CreateAssistantDtoModel_Anthropic(
                model="claude-sonnet-4-6",
                messages=[OpenAiMessage(role="system", content=system_prompt)],
                tool_ids=["YOUR_TOOL_ID"],
            ),
            voice=CreateAssistantDtoVoice_Vapi(voice_id="Elliot"),
            transcriber=CreateAssistantDtoTranscriber_Deepgram(
                model="nova-2",
                language="en",
            ),
            first_message="Hey I'm Harry, a support agent. How can I help you today? You can ask me questions about Vapi, how to get started, or our documentation.",
            end_call_message="Goodbye.",
            background_sound="off",
        )

        print(f"Assistant created with ID: {assistant.id}")
        ```
      </Tab>

  <Step title="Create a React voice widget">
    In an existing React project, use the Vapi Web SDK to create a voice widget for your documentation assistant.

    <Tabs>
      <Tab title="React (Web SDK)">
        <CodeBlocks>
        ```bash title="npm"
        npm install @vapi-ai/web
        ```

        ```bash title="yarn"
        yarn add @vapi-ai/web
        ```

        ```bash title="pnpm"
        pnpm add @vapi-ai/web
        ```

        ```bash title="bun"
        bun add @vapi-ai/web
        ```
        </CodeBlocks>

        Replace `YOUR_PUBLIC_API_KEY` and `YOUR_ASSISTANT_ID` with your actual values:

        ```tsx
        import { useEffect, useState } from 'react';
        import Vapi from '@vapi-ai/web';

        type TranscriptEntry = {
          role: 'assistant' | 'user';
          text: string;
        };

        export default function VoiceWidget() {
          const [vapi, setVapi] = useState<Vapi | null>(null);
          const [isConnected, setIsConnected] = useState(false);
          const [transcript, setTranscript] = useState<TranscriptEntry[]>([]);

          useEffect(() => {
            const vapiInstance = new Vapi('YOUR_PUBLIC_API_KEY');
            setVapi(vapiInstance);

            vapiInstance.on('call-start', () => setIsConnected(true));
            vapiInstance.on('call-end', () => setIsConnected(false));

            vapiInstance.on('message', (message) => {
              if (
                message?.type === 'transcript' &&
                message.transcriptType === 'final' &&
                (message.role === 'assistant' || message.role === 'user') &&
                typeof message.transcript === 'string'
              ) {
                setTranscript((previous) => [
                  ...previous,
                  { role: message.role, text: message.transcript },
                ]);
              }
            });

            return () => {
              vapiInstance.removeAllListeners();
              void vapiInstance.stop();
            };
          }, []);

          const startCall = () => {
            setTranscript([]);
            void vapi?.start('YOUR_ASSISTANT_ID');
          };
          const endCall = () => void vapi?.stop();

          return (
            <div style={{ position: 'fixed', bottom: 24, right: 24, background: '#000', color: '#fff', borderRadius: 12, padding: 20, width: 300 }}>
              {!isConnected ? (
                <button onClick={startCall} style={{ background: '#12A594', color: '#fff', border: 'none', borderRadius: 8, padding: '12px 24px' }}>
                  Start Voice Chat
                </button>
              ) : (
                <div>
                  <div style={{ maxHeight: 200, overflowY: 'auto', marginBottom: 16 }}>
                    {transcript.map((message, index) => (
                      <div key={index} style={{ marginBottom: 8, textAlign: message.role === 'user' ? 'right' : 'left' }}>
                        <span style={{ background: message.role === 'user' ? '#12A594' : '#333', padding: '8px 12px', borderRadius: 12, display: 'inline-block' }}>
                          {message.text}
                        </span>
                      </div>
                    ))}
                  </div>
                  <button onClick={endCall} style={{ background: '#e5e7eb', color: '#000', border: 'none', borderRadius: 8, padding: '8px 16px' }}>
                    End Call
                  </button>
                </div>
              )}
            </div>
          );
        }
        ```
      </Tab>

  <Step title="Review calls and improve your prompts">
    After a call ends, review its transcript, messages, and tool activity. Look for the questions users ask, how the assistant searches the index, and where its answers need improvement.

    <Tabs>
      <Tab title="Dashboard">
        1. Navigate to **Observe** > **Logs**, then select **Calls**.
        2. Select a completed call to view its details.
        3. Review the transcript, messages, and tool activity.
        4. Use insights to improve your assistant's prompts and responses.
      </Tab>
      <Tab title="TypeScript (Server SDK)">
        ```typescript
        import { VapiClient } from "@vapi-ai/server-sdk";

        const vapi = new VapiClient({ token: "YOUR_VAPI_PRIVATE_API_KEY" });

        async function reviewCall(callId: string) {
          const call = await vapi.calls.get({ id: callId });

          console.log("Transcript:", call.artifact?.transcript);
          console.log("Messages:", call.artifact?.messages);

          return call;
        }

        await reviewCall("CALL_ID");
        ```
      </Tab>
      <Tab title="Python (Server SDK)">
        ```python
        from vapi import Vapi

        client = Vapi(token="YOUR_VAPI_PRIVATE_API_KEY")
        call = client.calls.get(id="CALL_ID")

        if call.artifact:
            print("Transcript:", call.artifact.transcript)
            print("Messages:", call.artifact.messages)
        ```
      </Tab>
      <Tab title="cURL">
        Retrieve the completed call using the Get Call API:

        ```bash
        curl --request GET \
          --url https://api.vapi.ai/call/CALL_ID \
          --header "Authorization: Bearer YOUR_VAPI_PRIVATE_API_KEY"
        ```
      </Tab>
    </Tabs>

    Review several calls before drawing conclusions. Update the system prompt when the same misunderstanding appears repeatedly. Refine the `docsquery` description or request schema when the assistant searches with incomplete or irrelevant queries. For automated summaries and evaluations, configure [structured outputs](/assistants/structured-outputs-quickstart).
  </Step>
