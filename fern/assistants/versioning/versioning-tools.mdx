## Overview

Tools follow the standard [versioning lifecycle](/assistants/versioning): you edit a draft, publish it to create a new version, and can restore an earlier one. A tool's versions are managed independently of any assistant — assistants then reference a specific tool version (or the latest). See [How versioning works with assistants and tools](/assistants/versioning/versioning-with-assistants-and-tools).

## Restore a previous version

Restoring a tool works the same way as restoring an assistant: it publishes a **new** version that copies the older one and becomes current (for example, restoring `v6` creates a new `v8`), and any unpublished draft changes are discarded.

<Note>
Tools and assistants are versioned independently. Restoring a tool version does not change which tool version an assistant uses — an assistant keeps using the version you selected for it (or the latest, if that's what you chose). {/* TODO(versioning): confirm interaction with assistants */}
</Note>
