## How version pinning works

Assistants and tools are versioned independently, but they come together when an assistant uses a tool. For each tool an assistant uses, you choose which version is referenced, either a specific version or the latest. That choice is recorded when you publish the assistant, so restoring it later brings back the same tool versions.

## Choose a tool version in the Dashboard

The assistant's **Tools** tab shows a table of the tools the assistant uses, with columns for the tool name, type, and **Assign Tool Version**. You can attach a tool directly from here, without navigating to a separate screen.

In the **Assign Tool Version** column, pick a specific version or **Latest** for each tool. Choosing **Latest** means the tool automatically updates to its newest published version. Choosing a specific version pins the tool to that version until you change it.

## Use the latest version through the API

When you create an assistant or add a tool **through the API**, you can leave the tool's version unspecified. If you omit the version, the assistant uses the **latest**, which is the newest published version of that tool.

In the Dashboard, **Latest** is also a selectable option for each tool, so you can choose it explicitly instead of relying on the API default.

<Note>
This default exists to preserve **backwards compatibility**. When no version is specified, the assistant uses the latest, which matches existing API behavior. Most customers create assistants and place outbound calls through the API.
</Note>

## How rollback affects tools

When you restore an assistant version, the tool versions it used are restored with it, except a tool set to `latest`, which always uses the newest version and is not rolled back.

Worked example:

- At **v6**, the assistant uses **Tool A v4** and **Tool B v6**.
- You restore the assistant to **v5**, which used **Tool A v2** and **Tool B v4**.
- After restoring, the assistant uses Tool A v2 and Tool B v4.
- If you had set Tool B to **latest** instead of a fixed version, it would keep using the newest published Tool B version after the restore. It would not roll back.
