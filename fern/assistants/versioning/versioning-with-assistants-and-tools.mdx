## How version pinning works

Assistants and tools are [versioned independently](/assistants/versioning), but an assistant configuration records which version of each tool to use. You can select a specific version or **Latest**. When you publish the assistant, Vapi saves those selections in the assistant version.

## Choose a tool version in the Dashboard

Open an [assistant](/assistants) and select the **Tools** tab. The table lists each tool and its **Assign Tool Version** selection. You can also add a tool from this tab.

In the **Assign Tool Version** column, select one of these options:

- **Latest**: The assistant always uses the tool's newest published version.
- **Specific version**: The assistant stays on the selected version until you change the selection and publish the assistant again.

## Use the latest tool version through the API

When you [create](/api-reference/assistants/create) or [update](/api-reference/assistants/update) an assistant through the API, omit the tool version to use **Latest**. The assistant then uses the newest published version of that tool.

## How restoring an assistant affects tools

When you restore an assistant version, Vapi loads its saved tool version selections into the draft. A specific tool version returns to the saved selection. A tool set to **Latest** continues to use its newest published version.

For example:

- At **v6**, the assistant uses **Tool A v4** and **Tool B v6**.
- The assistant's **v5** configuration used **Tool A v2** and **Tool B v4**.
- You restore assistant **v5**. Vapi loads Tool A v2 and Tool B v4 into the assistant draft.
- You review and publish the draft as the next assistant version.
- If Tool B was set to **Latest** in assistant v5, it continues to use the newest published Tool B version.
