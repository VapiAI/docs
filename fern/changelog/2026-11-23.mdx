# What's New: Week of November 23, 2026

## New models and transcribers

1. **GPT-6.1 Terra**: OpenAI's [GPT-6.1 Terra](/providers/model/openai) model (`gpt-6.1-terra`) is now available, with tool calls, parallel tool calls, and structured outputs. Its default reasoning effort is `low`, and `minimal` isn't supported.
2. **ElevenLabs Scribe v3 Live**: [ElevenLabs transcribers](/providers/transcriber/elevenlabs) now support Scribe v3 Live (`scribe_v3_live`), shown as Beta in the Dashboard. Set `language` to `multi` to transcribe callers who switch languages during a call, and use the new `languages` list to hint which languages to expect. Scribe v3 Live accepts `keyterms`, up to 50 terms of 20 characters each.

## Features

3. **Keypad entries without a reply**: [Keypad input](/documentation/assistants/conversation-behavior/keypad-input-settings) has two new settings in `keypadInputPlan`, both off by default. Set `triggerResponseEnabled` to `false` to add the caller's keypad entry to the conversation without the assistant replying right away; the assistant sees it on the caller's next turn. Set `variableName` to save each entry as a call variable, with leading zeros kept, so you can use it in a transfer destination such as a SIP header.
4. **Interruptions in Japanese, Chinese, Cantonese, and Thai**: Callers speaking Japanese, Chinese, Cantonese, or Thai can now interrupt the assistant when the [stop speaking plan's](/customization/speech-configuration) `numWords` is 2 or more. Words in these languages are now counted individually, instead of a whole sentence counting as one word.

## Fixes and improvements

5. **Assistant turns after a voice fallback**: Fixed missing assistant turns in transcripts and conversation history when calls using ElevenLabs with `modelOutputInMessagesEnabled` enabled switch to a non-ElevenLabs [fallback voice](/voice-fallback-plan).
6. **Fallback voice recovery**: The [fallback voice](/voice-fallback-plan) now takes over in more cases: when a message fails partway through, when no audio arrives within 3 seconds, when audio stalls mid-reply, when Deepgram or ElevenLabs fails to connect three times in a row, and when a voice fails before an outbound call is answered. A message that failed is spoken again on the fallback voice, and a first message that already started playing isn't repeated.
7. **Custom voice server errors**: When a [custom voice](/customization/custom-voices/custom-tts) server returns an HTTP error or doesn't respond, the voice now fails and the fallback voice takes over. Without a fallback voice, the call ends with `pipeline-error-custom-voice-failed`. Before, the caller heard the error as noise or the voice went silent.
8. **Soniox default model**: [Soniox transcribers](/providers/transcriber/soniox) with no `model` set now use `stt-rt-v6` instead of `stt-rt-v5`. Assistants that set v4 or v5 are unchanged.
