# What's New: Week of November 16, 2026

## New transcriber features

1. **ElevenLabs transcriber keyterms**: ElevenLabs Scribe v2 and Scribe v2 Realtime transcribers now accept a [`keyterms` list](/providers/transcriber/elevenlabs#keyterms) to improve recognition of names and domain terms. Scribe v2 takes up to 100 terms of 50 characters each, and Scribe v2 Realtime takes up to 50 terms of 20 characters each. Each term can be at most five words.

## Features

2. **Edit structured output schemas as JSON**: When the visual builder can't display a [structured output's](/assistants/structured-outputs-quickstart) schema, the dashboard now shows a JSON schema editor, so you can edit the schema there instead of only through the API. Saving or running a structured output now returns a [400 error](/assistants/structured-outputs#schema-refused-when-saving) when extraction can't use its schema, such as an array schema with no `items` or a `required` key missing from `properties`.

## Fixes and improvements

3. **Structured outputs on retiring models**: When a model retires, [structured outputs](/assistants/structured-outputs) saved in an assistant's `artifactPlan` that use the retired model now switch to its replacement model.
4. **Messages before a transfer or hang-up**: A message sent with [Live Call Control](/calls/call-features#transfer-the-call), such as the message spoken before a transfer, is now always spoken in full before the call transfers or ends. In some calls, the message was cut off or not spoken at all.
5. **Anthropic user keys**: [Anthropic](/providers/model/anthropic) API keys that start with `sk-ant-usr-` are now accepted.
