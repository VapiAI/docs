# What's New: Week of August 31, 2026

1. **Campaigns**: You can now create and run outbound [calling campaigns](/outbound-campaigns/overview) from the dashboard. Upload your contacts, pick an assistant, and track results as calls complete.

2. **Prompt Editor**: The assistant editor now includes a prompt editor where you can generate a prompt from a short description, insert variables, and search within your prompt.

3. **Soniox Endpoint Controls**: You can now tune the [Soniox transcriber's](/providers/transcriber/soniox) endpoint sensitivity and endpoint latency adjustment level for finer control over turn taking.

4. **Named Transfer Destinations**: You can now give each [transfer destination](/calls/call-dynamic-transfers) a friendly name that shows in your call logs instead of a raw phone number.

5. **Auto-Start Video Recording**: For web calls with [video recording](/assistants/call-recording) enabled, the recording now starts automatically when the caller joins, so your video recordings are captured reliably. This requires upgrading to the latest web SDK version.
