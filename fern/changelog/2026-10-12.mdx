# What's New: Week of October 12, 2026

1. **Traffic splitting**: You can now [split assistant traffic](/assistants/versioning/traffic-splitting) across published versions by percentage when you publish, so you can canary a new version and roll back instantly, with a live traffic view in the assistant header.
2. **Version-aware call logs**: You can now filter your call logs by [assistant version](/assistants/versioning) in each assistant's Logs tab.
3. **GPT-Live keypad input and Google/Slack tools (Beta)**: [GPT-Live](/gpt-live/overview) calls can now accept incoming keypad (DTMF) input on phone calls, and Google Calendar, Google Sheets, and Slack tools now run on the GPT-Live reasoner.
4. **Squad builder refresh**: Selecting a squad assistant now opens the assistant's settings in a side panel on the right. Options and settings for the [squad](/squads) are now in the Talk menu and the More actions (⋮) menu, and you can add an assistant from the left sidebar.

## New Models

1. **DeepSeek Flash**: DeepSeek's [`deepseek-flash`](/providers/model/deepseek) model is now available for assistants when you connect your DeepSeek account.

## Fixes and Improvements

1. **Call log playback**: In call detail you can now click a message to play it, with new waveform view options.
2. **Krisp denoiser**: Fixed Krisp failing at a 24 kHz sample rate, fixed denoised audio sometimes sounding stretched on websocket calls, and denoiser failures now appear in the call log.
3. **Simulations**: Fixed an issue where simulation runs could get stuck reconnecting while catching up on live progress.
