Vapi can connect an assistant to an external service through a prebuilt integration or a standard tool such as [API Request](/tools/api-request), [Model Context Protocol (MCP)](/tools/mcp), or [Function](/tools/custom-tools).

Use the service guides below to choose the appropriate connection pattern and configure the integration.

## Available integrations

<CardGroup cols={2}>
  <Card title="Make" icon="diagram-project" href="/tools/integrations/make">
    Connect Make through an API Request, MCP, or Function tool, depending on the data and context the scenario needs.
  </Card>
  <Card title="Google Calendar" icon="calendar-days" href="/tools/google-calendar">
    Create calendar events and check availability so an assistant can schedule appointments on a call.
  </Card>
  <Card title="Google Sheets" icon="table" href="/tools/google-sheets">

  </Card>
  <Card title="Slack" icon="slack" href="/tools/slack">
    Send a message to a configured channel so your team is notified during or after a call.
  </Card>
  <Card title="GoHighLevel" icon="arrow-up" href="/tools/go-high-level">
    Manage contacts, check calendar availability, and book appointments in GoHighLevel.
  </Card>
</CardGroup>
