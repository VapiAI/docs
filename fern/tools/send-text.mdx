The Send Text tool is a built-in tool that lets your assistant send a text message (SMS) during a voice call. The text is sent from a Twilio phone number that you imported into Vapi, through your Twilio account.

<Info>
  When you send or receive SMS messages, you are responsible for following the messaging laws and carrier requirements that apply where your recipients are located. For details, see the [Vapi Terms of Service](https://vapi.ai/terms-of-service) and the [Twilio Messaging Policy](https://www.twilio.com/en-us/legal/messaging-policy).
</Info>

## When to use the Send Text tool

Use the Send Text tool when the caller asks for details they'll want to keep after the call ends. Common examples:

- **Confirm an appointment.** After your assistant books an appointment, it texts the caller the date, time, and address.
- **Send a link.** Your assistant texts a link to a form, a payment page, or a reschedule page, so the caller doesn't have to write down a URL.
- **Share details that are hard to hear.** Your assistant texts an order number, a reference code, or an address that's easier to read than to listen to.

To handle texts that people send to your number, see [SMS chat](/chat/sms-chat).

## Limits

Each time the assistant calls the tool, it sends one text. The tool has these limits:

- It only sends text messages.
- It works during phone calls and web calls, but not in [chats](/chat/quickstart).
- It isn't available on [GPT-Live](/gpt-live/configuration) models.

## Requirements

- **A Twilio phone number imported into Vapi.** The text is sent from this number. See [Import a Twilio number](/phone-numbers/import-twilio). Numbers from other providers, including free Vapi numbers, Telnyx, Vonage, and BYO SIP trunks, can't send texts with this tool.
- **US phone numbers only.** Both the sender and the recipient must be US phone numbers.
- **SMS sending enabled in Twilio.** The number must be able to send SMS messages in Twilio. Register the number for [application-to-person 10-digit long code (A2P 10DLC)](https://www.twilio.com/docs/messaging/compliance/a2p-10dlc) messaging, or [verify it](https://www.twilio.com/docs/messaging/compliance/toll-free/console-onboarding) if it's a toll-free number.

## Send Text tool and SMS chat

Vapi has two SMS features. They work differently:

| | Send Text tool | SMS chat |
| --- | --- | --- |
| What happens | Your assistant sends a text during a voice call | A person texts your number and your assistant replies by text |
| Who starts it | Your assistant | The person texting |
| Setup | Add the Send Text tool to your assistant | Import a Twilio number with **SMS Enabled** and assign an assistant |
| Learn more | This page | [SMS chat](/chat/sms-chat) |

## How the tool works during a call

When your assistant calls the tool, the assistant fills in the recipient's phone number and the message, unless you preset them:

- **Recipient.** By default, the assistant chooses the number. It can text the caller or another number given during the call. If it doesn't provide a number, the text goes to the caller. To make sure the assistant only texts the caller, preset the recipient. See [Send texts only to the caller](/tools/send-text/configure#send-texts-only-to-the-caller).
- **Message.** By default, the assistant writes the message. To send the same wording every time, preset the message. Presets can include [variables](/assistants/dynamic-variables).

A preset always overrides what the assistant would fill in.

The assistant gets back a result: success, or an error that explains what went wrong. A success result means Twilio accepted the message, not that it was delivered.
