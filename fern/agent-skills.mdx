Vapi Skills are instruction packages that help compatible AI coding assistants complete Vapi development tasks. Choose a skill for the task you want to do, such as creating an assistant, configuring a tool, or testing a Squad. The [latest Vapi Skills release](https://github.com/VapiAI/skills/releases/latest) provides a ZIP for each skill.

## Install Vapi Skills

Download a skill ZIP from the [latest release](https://github.com/VapiAI/skills/releases/latest). Each skill below links to its ZIP in that release.

To install directly from the repository with the Skills CLI instead, run:

```bash
npx skills add VapiAI/skills
```

To install one skill, pass its name. For example, to work on a Squad:

```bash
npx skills add VapiAI/skills --skill create-squad
```

For skill directory locations and other installation methods, see the [repository installation instructions](https://github.com/VapiAI/skills#installation). For live Vapi API operations, configure a private API key as `VAPI_API_KEY` in your environment. Follow the [API key security guidance](/security-and-privacy/api-keys); keep private keys out of chats and source code.

## Choose a skill

Each skill below links to a ZIP in the latest release. The related docs explain the Vapi feature and its configuration.

### setup-api-key

Use [setup-api-key (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/setup-api-key.zip) to get and configure a Vapi API key, including when a missing key blocks API calls. See [API keys](/security-and-privacy/api-keys).

### create-assistant

Use [create-assistant (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-assistant.zip) to design, create, or validate a saved or transient assistant. See the [assistants quickstart](/assistants/quickstart).

### create-structured-output

Use [create-structured-output (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-structured-output.zip) to design, attach, and verify reusable post-call data extraction. See [structured outputs](/assistants/structured-outputs).

### vapi-prompt-builder

Use [vapi-prompt-builder (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/vapi-prompt-builder.zip) to draft, improve, or review assistant and Squad system prompts. See the [Voice AI Prompting Guide](/prompting-guide).

### create-tool

Use [create-tool (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-tool.zip) to select, configure, attach, and verify tools for an assistant. See [Tools](/tools).

### create-call

Use [create-call (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-call.zip) for a single outbound phone call, a web call, a scheduled call, or a simple batch. See [Outbound Calling](/calls/outbound-calling).

### create-campaign

Use [create-campaign (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-campaign.zip) for a persistent outbound campaign with contacts, scheduling, results, and lifecycle management. See [Campaigns overview](/outbound-campaigns/overview).

### create-squad

Use [create-squad (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-squad.zip) to design Squad members and handoffs, then create or verify the Squad configuration. See [Squads](/squads).

### create-phone-number

Use [create-phone-number (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-phone-number.zip) to plan, provision, import, or route a Vapi phone number. See [Phone Calling](/phone-calling).

### setup-webhook

Use [setup-webhook (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/setup-webhook.zip) to configure a Server URL that receives call events or tool calls. See [Server URLs](/server-url).

### simulations

Use [simulations (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/simulations.zip) to design, run, and maintain conversation tests for assistants and Squads. See [Simulations overview](/observability/simulations-overview).
