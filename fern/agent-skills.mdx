Agent skills for Vapi are instruction packages that help compatible AI coding assistants build and test voice assistants. This page explains how to install agent skills and choose one for tasks such as creating an assistant, configuring a tool, or testing a Squad.

## Install agent skills

To install agent skills for Vapi, download a skill ZIP from the [latest release](https://github.com/VapiAI/skills/releases/latest). Each skill below links to its ZIP in that release. For skill directory locations and other installation methods, see the [repository installation instructions](https://github.com/VapiAI/skills#installation).

To install directly from the repository with the Skills CLI instead, run:

```bash
npx skills add VapiAI/skills
```

To install one skill, pass its name. For example, to work on a Squad:

```bash
npx skills add VapiAI/skills --skill create-squad
```

For live API operations, configure a private API key as `VAPI_API_KEY` in your environment. Follow the [API key security guidance](/security-and-privacy/api-keys); keep private keys out of chats and source code.

## Choose a skill

Each skill below links to a ZIP in the latest release. The related docs explain each feature and its configuration.

### setup-api-key

Use the [setup-api-key agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/setup-api-key.zip) to get and configure an API key, including when a missing key blocks API calls. See [API keys](/security-and-privacy/api-keys).

### create-assistant

Use the [create-assistant agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-assistant.zip) to design, create, or validate a saved or transient assistant. See the [assistants quickstart](/assistants/quickstart).

### create-structured-output

Use the [create-structured-output agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-structured-output.zip) to design, attach, and verify reusable post-call data extraction. See [structured outputs](/assistants/structured-outputs).

### vapi-prompt-builder

Use the [vapi-prompt-builder agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/vapi-prompt-builder.zip) to draft, improve, or review assistant and Squad system prompts. See the [Voice AI Prompting Guide](/prompting-guide).

### create-tool

Use the [create-tool agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-tool.zip) to select, configure, attach, and verify tools for an assistant. See [Tools](/tools).

### create-call

Use the [create-call agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-call.zip) to place an outbound phone call, start a web call, schedule a call, or run a simple batch of calls. See [Outbound Calling](/calls/outbound-calling).

### create-campaign

Use the [create-campaign agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-campaign.zip) to create and manage a persistent outbound campaign with contacts, scheduling, and results. See [Campaigns overview](/outbound-campaigns/overview).

### create-squad

Use the [create-squad agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-squad.zip) to design Squad members and handoffs, then create or verify the Squad configuration. See [Squads](/squads).

### create-phone-number

Use the [create-phone-number agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/create-phone-number.zip) to plan, provision, import, or route a phone number. See [Phone Calling](/phone-calling).

### setup-webhook

Use the [setup-webhook agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/setup-webhook.zip) to configure a Server URL that receives call events or tool calls. See [Server URLs](/server-url).

### simulations

Use the [simulations agent skill (ZIP)](https://github.com/VapiAI/skills/releases/latest/download/simulations.zip) to design, run, and maintain conversation tests for assistants and Squads. See [Simulations overview](/observability/simulations-overview).
