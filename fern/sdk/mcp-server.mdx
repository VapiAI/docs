## Overview

The **Vapi MCP Server** gives AI agents Vapi tools over the Model Context Protocol (MCP). Once connected, your agent can search Vapi's documentation and manage your assistants, phone numbers, and calls.

Vapi hosts the server at `https://mcp.vapi.ai/mcp`, using the **Streamable HTTP** transport. Add it in your agent's MCP settings; you don't need the Vapi CLI. You can also [run the server locally](#run-the-server-locally).

<Note>
  Looking to use MCP tools *inside* a Vapi assistant? See [MCP tools](/tools/mcp).
</Note>

## Connect your agent

Get a [Vapi API key](/security-and-privacy/api-keys), then choose your agent.

<Tabs>
  <Tab title="Codex">
    For the Codex CLI, set your API key and register the remote server:

    ```bash
    export VAPI_API_KEY="YOUR_VAPI_API_KEY"
    codex mcp add vapi --url https://mcp.vapi.ai/mcp \
      --bearer-token-env-var VAPI_API_KEY
    codex mcp list
    ```

    Codex saves the connection in `~/.codex/config.toml` and reads the key from `VAPI_API_KEY` when it connects. Keep that variable available whenever you launch Codex. If you use the desktop app or IDE extension, its launch environment must also contain the variable.

    Start a new Codex session and use `/mcp` to inspect the connection. See [Codex MCP setup](https://developers.openai.com/codex/mcp).
  </Tab>
  <Tab title="Claude Code">
    Set your API key and add the server to your private user configuration:

    ```bash
    export VAPI_API_KEY="YOUR_VAPI_API_KEY"
    claude mcp add --transport http --scope user vapi \
      https://mcp.vapi.ai/mcp \
      --header 'Authorization: Bearer ${VAPI_API_KEY}'
    claude mcp get vapi
    ```

    The single quotes preserve the environment-variable reference in `~/.claude.json`. Keep `VAPI_API_KEY` set whenever you launch Claude Code. Start a new session and use `/mcp` to check the connection.

    See [Claude Code MCP setup](https://code.claude.com/docs/en/mcp).
  </Tab>
  <Tab title="Hermes">
    Register the hosted server with header authentication:

    ```bash
    hermes mcp add vapi --url https://mcp.vapi.ai/mcp --auth header
    ```

    Confirm that the server requires authentication, then paste your Vapi API key at the masked **API key / Bearer token** prompt. Enter the key without the `Bearer` prefix. Select the tools you want to enable and finish saving the connection.

    Hermes saves the connection in your active profile's `config.yaml` and the key in its `.env` file. Start a new session, or run `/reload-mcp` in an existing session. To test the connection:

    ```bash
    hermes mcp test vapi
    ```

    See [Hermes MCP setup](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp).
  </Tab>
  <Tab title="Cursor">
    Add this entry to your private user configuration at `~/.cursor/mcp.json`, preserving any other servers:

    ```json
    {
      "mcpServers": {
        "vapi": {
          "url": "https://mcp.vapi.ai/mcp",
          "headers": {
            "Authorization": "Bearer YOUR_VAPI_API_KEY"
          }
        }
      }
    }
    ```

    Replace `YOUR_VAPI_API_KEY` with your Vapi API key. Open Cursor's MCP settings and enable `vapi`, then start a new chat. Keep this user configuration private and update the header after rotating your key.

    See [Cursor MCP setup](https://cursor.com/docs/mcp).
  </Tab>
  <Tab title="VS Code">
    Run **MCP: Open User Configuration** from the Command Palette. Add this entry to `mcp.json`, preserving any other servers:

    ```json
    {
      "inputs": [
        {
          "type": "promptString",
          "id": "vapi-api-key",
          "description": "Vapi API key",
          "password": true
        }
      ],
      "servers": {
        "vapi": {
          "type": "http",
          "url": "https://mcp.vapi.ai/mcp",
          "headers": {
            "Authorization": "Bearer ${input:vapi-api-key}"
          }
        }
      }
    }
    ```

    Start `vapi` from **MCP: List Servers** and enter your API key when prompted. Then use a **Local** chat session and enable the server's tools. Other session types can't prompt for the key, so this server isn't available in them.

    See [VS Code MCP setup](https://code.visualstudio.com/docs/agents/reference/mcp-configuration).
  </Tab>
  <Tab title="Claude Desktop">
    Claude Desktop's configuration file runs local commands, so use `mcp-remote` as a bridge to the hosted server. This requires Node.js and `npx` to be available to Claude Desktop.

    Open **Settings → Developer → Edit Config**. Add this entry to `claude_desktop_config.json`, preserving any other servers:

    ```json
    {
      "mcpServers": {
        "vapi": {
          "command": "npx",
          "args": [
            "-y",
            "mcp-remote",
            "https://mcp.vapi.ai/mcp",
            "--transport",
            "http-only",
            "--header",
            "Authorization: Bearer ${VAPI_API_KEY}"
          ],
          "env": {
            "VAPI_API_KEY": "YOUR_VAPI_API_KEY"
          }
        }
      }
    }
    ```

    Replace `YOUR_VAPI_API_KEY` with your Vapi API key and restart Claude Desktop. Keep this configuration private and update the key after rotating it. The bridge runs locally; Vapi's MCP server stays hosted.
  </Tab>
</Tabs>

Once connected, try asking your agent: "List my Vapi assistants."

<Note>
  **Replacing an older setup?** If your agent uses `@vapi-ai/mcp-docs-server` from an earlier CLI release, or the deprecated `https://mcp.vapi.ai/sse` endpoint, replace that entry with the hosted connection above. The hosted server includes documentation search. Existing agent configurations are not changed automatically.
</Note>

## Run the server locally

You can run the open-source [Vapi MCP server](https://github.com/VapiAI/mcp-server) on your own machine instead of connecting to the hosted one, for example to develop against it. This requires Node.js. Your client starts the server as a subprocess and talks to it over stdio, so no HTTP endpoint is started.

Add this entry to your client's MCP configuration in place of the hosted connection. The local server reads your API key from `VAPI_TOKEN`:

```json
{
  "mcpServers": {
    "vapi": {
      "command": "npx",
      "args": ["-y", "@vapi-ai/mcp-server"],
      "env": {
        "VAPI_TOKEN": "YOUR_VAPI_API_KEY"
      }
    }
  }
}
```

In Claude Code, run:

```bash
claude mcp add -e VAPI_TOKEN=YOUR_VAPI_API_KEY vapi -- npx -y @vapi-ai/mcp-server
```

## Core tools

The Vapi MCP Server exposes these tools:

| Tool                   | Description                                      | Example usage                                 |
|------------------------|--------------------------------------------------|-----------------------------------------------|
| `ask_vapi_docs`        | Search Vapi documentation                        | Ask how a Vapi feature works                  |
| `list_assistants`      | List all Vapi assistants                         | Show all configured assistants                |
| `create_assistant`     | Create a new Vapi assistant                      | Add a new assistant for a use case            |
| `get_assistant`        | Get a Vapi assistant by ID                       | View assistant config                         |
| `list_calls`           | List all calls                                   | Review call activity                          |
| `create_call`          | Create an outbound call (now or scheduled)       | Initiate or schedule a call                   |
| `get_call`             | Get details for a specific call                  | Check status or result of a call              |
| `list_phone_numbers`   | List all Vapi phone numbers                      | See available numbers                         |
| `get_phone_number`     | Get details of a specific phone number           | Inspect a phone number                        |
| `list_tools`           | List all available Vapi tools                    | Tool discovery                                |
| `get_tool`             | Get details of a specific tool                   | Tool integration info                         |

To schedule a call, pass the optional `scheduledAt` parameter to `create_call`. `create_call` places a real phone call.

## Use the server from your own code

Connect any MCP client to `https://mcp.vapi.ai/mcp` over Streamable HTTP, and send your Vapi API key in the `Authorization: Bearer YOUR_VAPI_API_KEY` header.

### OpenAI Responses API

The OpenAI Responses API can call remote MCP servers. See [OpenAI's remote MCP guide](https://platform.openai.com/docs/guides/tools-remote-mcp).

<CodeBlocks>
```typescript title="typescript"
import OpenAI from 'openai';
// Replace with your actual OpenAI API key
const openai = new OpenAI({ apiKey: 'YOUR_OPENAI_API_KEY' });
async function main() {
  const response = await openai.responses.create({
    model: 'gpt-4.1',
    tools: [
      {
        type: 'mcp',
        server_label: 'vapi-mcp',
        server_url: 'https://mcp.vapi.ai/mcp',
        headers: { "Authorization": "Bearer YOUR_VAPI_API_KEY" }
      },
    ],
    input: 'What vapi tools do you have available?',
  });
  console.dir(response, { depth: null });
}
main();
```
```python title="python"
import openai
# Replace with your actual OpenAI API key
openai.api_key = 'YOUR_OPENAI_API_KEY'
response = openai.responses.create(
    model="gpt-4.1",
    tools=[
        {
            "type": "mcp",
            "server_label": "vapi-mcp",
            "server_url": "https://mcp.vapi.ai/mcp",
            "headers": {"Authorization": "Bearer YOUR_VAPI_API_KEY"}
        },
    ],
    input="What vapi tools do you have available?",
)
print(response)
```

### MCP client SDKs

Official MCP SDKs are available for [TypeScript](https://github.com/modelcontextprotocol/typescript-sdk), [Python](https://github.com/modelcontextprotocol/python-sdk), [Java](https://github.com/modelcontextprotocol/java-sdk), [Kotlin](https://github.com/modelcontextprotocol/kotlin-sdk), and [C#](https://github.com/modelcontextprotocol/csharp-sdk). This minimal Node.js client lists your assistants:

```javascript
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js';
import dotenv from 'dotenv';

dotenv.config();

const mcpClient = new Client({ name: 'vapi-client', version: '1.0.0' });
const transport = new StreamableHTTPClientTransport(
  new URL('https://mcp.vapi.ai/mcp'),
  { requestInit: { headers: { Authorization: `Bearer ${process.env.VAPI_API_KEY}` } } }
);

async function main() {
  await mcpClient.connect(transport);
  const assistants = await mcpClient.callTool({ name: 'list_assistants', arguments: {} });
  console.log(assistants);
  await mcpClient.close();
}

main();
```

This fuller example lists tools, assistants, and phone numbers, then creates a call:

```javascript
#!/usr/bin/env node
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js';
import dotenv from 'dotenv';

// Load environment variables from .env file
dotenv.config();

// Ensure API key is available
if (!process.env.VAPI_API_KEY) {
  console.error('Error: VAPI_API_KEY environment variable is required');
  process.exit(1);
}

async function main() {
  try {
    // Initialize MCP client
    const mcpClient = new Client({
      name: 'vapi-client-example',
      version: '1.0.0',
    });
    // Create Streamable HTTP transport for connection to remote Vapi MCP server
    const serverUrl = 'https://mcp.vapi.ai/mcp';
    const headers = {
      Authorization: `Bearer ${process.env.VAPI_API_KEY}`,
    };
    const options = {
      requestInit: { headers: headers },
    };
    const transport = new StreamableHTTPClientTransport(new URL(serverUrl), options);
    console.log('Connecting to Vapi MCP server via Streamable HTTP...');
    await mcpClient.connect(transport);
    console.log('Connected successfully');

    // Helper function to parse tool responses
    function parseToolResponse(response) {
      if (!response?.content) return response;
      const textItem = response.content.find(item => item.type === 'text');
      if (textItem?.text) {
        try {
          return JSON.parse(textItem.text);
        } catch {
          return textItem.text;
        }
      }
      return response;
    }

    try {
      // List available tools
      const toolsResult = await mcpClient.listTools();
      console.log('Available tools:');
      toolsResult.tools.forEach((tool) => {
        console.log(`- ${tool.name}: ${tool.description}`);
      });

      // List assistants
      console.log('\nListing assistants...');
      const assistantsResponse = await mcpClient.callTool({
        name: 'list_assistants',
        arguments: {},
      });
      const assistants = parseToolResponse(assistantsResponse);
      if (!(Array.isArray(assistants) && assistants.length > 0)) {
        console.log('No assistants found. Please create an assistant in the Vapi dashboard first.');
        return;
      }
      console.log('Your assistants:');
      assistants.forEach((assistant) => {
        console.log(`- ${assistant.name} (${assistant.id})`);
      });

      // List phone numbers
      console.log('\nListing phone numbers...');
      const phoneNumbersResponse = await mcpClient.callTool({
        name: 'list_phone_numbers',
        arguments: {},
      });
      const phoneNumbers = parseToolResponse(phoneNumbersResponse);
      if (!(Array.isArray(phoneNumbers) && phoneNumbers.length > 0)) {
        console.log('No phone numbers found. Please add a phone number in the Vapi dashboard first.');
        return;
      }
      console.log('Your phone numbers:');
      phoneNumbers.forEach((phoneNumber) => {
        console.log(`- ${phoneNumber.phoneNumber} (${phoneNumber.id})`);
      });

      // Create a call using the first assistant and first phone number.
      // Outbound calls need an imported number. With free Vapi numbers, only inbound calls are supported.
      const phoneNumberId = phoneNumbers[0].id;
      const assistantId = assistants[0].id;
      console.log(`\nCreating a call using assistant (${assistantId}) and phone number (${phoneNumberId})...`);
      const createCallResponse = await mcpClient.callTool({
        name: 'create_call',
        arguments: {
          assistantId: assistantId,
          phoneNumberId: phoneNumberId,
          customer: {
            number: "+1234567890"  // Replace with actual customer phone number
          }
          // Optional: schedule a call for the future
          // scheduledAt: "2025-04-15T15:30:00Z"
          // assistantOverrides: {
          //  variableValues: {
          //   name: 'John Doe',
          //   age: '25',
          //  },
          // },
        },
      });
      const createdCall = parseToolResponse(createCallResponse);
      console.log('Call created:', JSON.stringify(createdCall, null, 2));
    } finally {
      console.log('\nDisconnecting from server...');
      await mcpClient.close();
      console.log('Disconnected');
    }
  } catch (error) {
    console.error('Error:', error);
    process.exit(1);
  }
}

main();
```
