Audit logs record actions that members take in your organization, such as signing in, changing a member's role, or updating an assistant. Use them to review activity for security and compliance.

## Prerequisites

- An Enterprise plan or the **Premier** Success Package.
- An **Admin** role in the organization. To change a member's role, see [Manage members and roles](/security-and-privacy/members-and-roles).

## Open audit logs

<Steps>
  <Step title="Open the Audit logs page">
    Sign in to the [Vapi Dashboard](https://dashboard.vapi.ai), select the organization, open **Settings**, then select **Audit logs**.
  </Step>

  <Step title="Open the audit log portal">
    Select **Open Audit Log Portal**. The audit log portal, hosted by WorkOS, opens in a new browser tab.

    The link to the portal expires after 5 minutes. If it expires, return to the **Audit logs** page and select **Open Audit Log Portal** again.
  </Step>
</Steps>

<Tip>
If the portal doesn't open, allow pop-ups for the Vapi Dashboard in your browser, then try again.
</Tip>

## What audit logs record

Audit logs record these actions:

| Area | Recorded actions |
|------|------------------|
| Assistants | Created, updated, deleted, viewed |
| Tools | Created, updated, deleted, viewed |
| Credentials | Created, updated, deleted, viewed |
| Phone numbers | Created, imported, updated, deleted, viewed |
| Evals | Created, updated, viewed |
| Files | Uploaded, deleted, viewed |
| Calls | Deleted, viewed |
| Chats | Deleted, viewed |
| Sessions | Deleted, viewed |
| Logs | Viewed |
| Members | Signed in, signed out, password reset, role changed |
| Invitations | Sent, accepted |

If a member views the same item more than once within a minute, the audit log records one view.

## What each entry includes

Each audit log entry includes:

- **Actor:** The member who performed the action.
- **Action:** What the member did, such as creating an assistant.
- **Target:** The item the action affected, with its ID.
- **Location:** The IP address the action came from.
- **User agent:** The browser or client used.
- **Time:** When the action happened.

When Vapi support acts on your organization while helping you, the entry shows the Vapi support user and the member they acted as.
