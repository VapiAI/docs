Azure provides speech-to-text for Vapi voice agents.

You can use Azure through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Speech-to-text | `azure` |

## Speech-to-text

Set `transcriber.provider` to `azure`. Azure transcription (Azure Speech) supports a wide range of languages.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": { "provider": "azure" }
  }'
```

For additional API configuration options, review the [`AzureSpeechTranscriber` fields](/api-reference/assistants/create#request.body.transcriber.AzureSpeechTranscriber) in the Create Assistant API reference.
