xAI provides speech-to-text for Vapi voice agents.

You can use xAI through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Speech-to-text | `xai` |

## Speech-to-text

Set `transcriber.provider` to `xai`. The optional `model` field currently accepts only `default`. Set `language` when you want deterministic language-specific formatting.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": {
      "provider": "xai",
      "model": "default",
      "language": "en"
    }
  }'
```

For additional API configuration options, review the [`XaiTranscriber` fields](/api-reference/assistants/create#request.body.transcriber.XaiTranscriber) in the Create Assistant API reference.

### Transcriber options

| Field | Required | Vapi behavior | Description |
| --- | --- | --- | --- |
| `model` | No | Uses xAI's current STT model | The only accepted value is `default`. |
| `language` | No | Defaults to English | An accepted language code used for deterministic transcription and formatting. |
