Cartesia provides speech-to-text for Vapi voice agents.

You can use Cartesia through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Speech-to-text | `cartesia` |

## Speech-to-text

Set `transcriber.provider` to `cartesia` and `transcriber.model` to a Cartesia model.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": { "provider": "cartesia", "model": "ink-whisper" }
  }'
```

For additional API configuration options, review the [`CartesiaTranscriber` fields](/api-reference/assistants/create#request.body.transcriber.CartesiaTranscriber) in the Create Assistant API reference.

| Model | Model ID |
| --- | --- |
| Ink Whisper | `ink-whisper` |
