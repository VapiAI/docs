OpenAI provides speech-to-text for Vapi voice agents.

You can use OpenAI through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Assistant property | Provider value |
| --- | --- | --- |
| Speech-to-text | `transcriber.provider` | `openai` |

## Speech-to-text

Set `transcriber.provider` to `openai` and `transcriber.model` to a transcription model.

| Model | Model ID |
| --- | --- |
| GPT-4o Transcribe | `gpt-4o-transcribe` |
| GPT-4o Mini Transcribe | `gpt-4o-mini-transcribe` |

```bash

  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": { "provider": "openai", "model": "gpt-4o-transcribe" }
  }'
```
