OpenAI provides speech-to-text for Vapi voice agents.

You can use OpenAI through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Speech-to-text | `openai` |

## Speech-to-text

Set `transcriber.provider` to `openai` and `transcriber.model` to a transcription model.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": { "provider": "openai", "model": "gpt-4o-transcribe" }
  }'
```

For additional API configuration options, review the [`OpenAITranscriber` fields](/api-reference/assistants/create#request.body.transcriber.OpenAITranscriber) in the Create Assistant API reference.

| Model | Model ID |
| --- | --- |
| GPT Transcribe | `gpt-transcribe` |
| GPT-4o Transcribe | `gpt-4o-transcribe` |
| GPT-4o Mini Transcribe | `gpt-4o-mini-transcribe` |

### Keywords and prompt

Two optional fields guide transcription:

- **[`keywords`](/api-reference/assistants/create#request.body.transcriber.OpenAITranscriber.keywords)**: An array of words and phrases the model should recognize, such as names, brands, and product terms. Supported only by `gpt-transcribe`. Each keyword is one line and can't contain `<` or `>`. Up to 16,384 keywords.
- **[`prompt`](/api-reference/assistants/create#request.body.transcriber.OpenAITranscriber.prompt)**: Free-text context for the transcription, such as the topic of the call or the expected vocabulary. Supported by all three models. Up to 8,192 characters for `gpt-transcribe`, and 1,024 for `gpt-4o-transcribe` and `gpt-4o-mini-transcribe`.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": {
      "provider": "openai",
      "model": "gpt-transcribe",
      "keywords": ["Vapi", "Acme Dental", "Invisalign"],
      "prompt": "A patient calling a dental office to book or change an appointment."
    }
  }'
```

<Note>
Digit formatting can differ by model. The `gpt-transcribe` model may write spoken digit strings as words (for example, "four seven two"), where `gpt-4o-transcribe` and `gpt-4o-mini-transcribe` may write them as digits ("472"). Don't rely on either format.
</Note>

For keyword options on other transcribers, see [Keywords and keyterm prompting](/customization/custom-keywords).
