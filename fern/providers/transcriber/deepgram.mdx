Deepgram provides speech-to-text for Vapi voice agents.

You can use Deepgram through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Speech-to-text | `deepgram` |

## Speech-to-text

Set `transcriber.provider` to `deepgram` and `transcriber.model` to a Deepgram model.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": { "provider": "deepgram", "model": "nova-3" }
  }'
```
