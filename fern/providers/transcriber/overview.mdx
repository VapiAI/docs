This page lists the speech-to-text (STT) providers Vapi supports, with each provider's ID and compliance coverage.

The transcriber converts the caller's speech to text for your voice agent. You select one by setting `transcriber.provider` and `transcriber.model` on an assistant. See [Create Assistant](/api-reference/assistants/create) in the API reference.

## Quick reference

Every column reflects Vapi's coverage for that provider. The provider string is the exact value you pass in `transcriber.provider`.

| Provider | Provider string | HIPAA | GDPR (EU region) |
| -- | -- | -- | -- |
| [AssemblyAI](/providers/transcriber/assembly-ai) | `assembly-ai` | No | No |
| [Azure](/providers/voice/azure) | `azure` | Yes | No |
| [Cartesia](/providers/voice/cartesia) | `cartesia` | Yes | Yes |
| [Deepgram](/providers/transcriber/deepgram) | `deepgram` | Yes | Yes |
| [ElevenLabs](/providers/voice/elevenlabs) | `11labs` | No | No |
| [Gladia](/providers/transcriber/gladia) | `gladia` | No | No |
| [Google](/providers/transcriber/google) | `google` | No | No |
| [OpenAI](/providers/voice/openai) | `openai` | No | Yes |
| [Soniox](/providers/transcriber/soniox) | `soniox` | Yes | Yes |
