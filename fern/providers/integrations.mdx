An integration connects your own provider account to Vapi, so a provider runs on your credentials instead of Vapi's. Use one when you want to run a provider on your own account, for example to use your own plan, rate limits, or custom models. This guide shows you how to add a provider's credentials to Vapi.

## How it works

By default, Vapi provides access to its supported providers, so you can select a voice, model, or transcriber on an assistant without any setup. You only add an integration when you want to use your own account with a provider.

When you add your own credentials for a provider, Vapi uses your account with that provider. If you don't add an integration, Vapi's default access is used.

## Prerequisites

* An account with the provider you want to connect.
* That provider's API key or credentials.

## Steps

<Steps>
  <Step title="Open Integrations in the dashboard">
    In the [Vapi Dashboard](https://dashboard.vapi.ai), open **Integrations**.
  </Step>
  <Step title="Select the provider">
    Choose the provider you want to connect from the list.
  </Step>
  <Step title="Add your credentials">
    Enter your provider API key or credentials and save. Vapi validates them when you save.
  </Step>
  <Step title="Use the provider on an assistant">
    Select the provider on an assistant as usual. Vapi now uses your account for that provider.
  </Step>
</Steps>

## Verify it works

After you save, the dashboard shows the provider as connected. Select the provider on an assistant and start a call or chat to confirm it runs on your account.
