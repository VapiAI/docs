## What is GPT-Live?

GPT-Live is an OpenAI voice model that listens and speaks at the same time. In Vapi, the speaker handles conversation while a separate reasoner handles delegated tasks and tools. See [GPT-Live architecture](/gpt-live/overview) for the responsibilities of each component.

## Connect GPT-Live

Your organization needs GPT-Live enabled. If you bring an OpenAI key, it must have access to GPT-Live and the selected reasoning model.

Follow the [GPT-Live quickstart](/gpt-live/quickstart) to create an assistant and make a web call. Add [tools](/gpt-live/tools) when you are ready to connect your services.

## Settings reference

| Setting | Configuration |
| --- | --- |
| Voice model | `model.provider: "openai"` and `model.model: "gpt-live-1"` |
| Speaker behavior | `model.speaker.instructions` |
| Reasoner behavior | `model.reasoner.instructions` |
| Reasoner selection | `model.reasoner.model` and `model.reasoner.reasoningEffort` |
| Voice | `voice.provider: "openai"` and a [supported voice ID](/gpt-live/voices) |

Use the [configuration and compatibility reference](/gpt-live/configuration) for defaults, transports, tool restrictions, and settings that do not apply. Learn to [design conversations](/gpt-live/conversation-design) and [test a migration](/gpt-live/testing) before moving an existing assistant.
