Cerebras is a large language model provider that runs open models with very fast inference. Connect Cerebras to use its Llama model as the LLM on a Vapi assistant. This page covers what Cerebras is and the model it supports.

## What is Cerebras

Cerebras serves open large language models on its own inference hardware, optimized for low latency. On Vapi, you select a Cerebras model as the LLM for a voice agent.

You can use Cerebras through Vapi's default integration, or use your own Cerebras account by connecting it in [Integrations](/providers/integrations).

## Language model

Set `model.provider` to `cerebras` and `model.model` to a Cerebras model.

| Model | Model value |
| -- | -- |
| Llama 3.1 8B | `llama3.1-8b` |

{/* verify: the dashboard offers only Llama 3.1 8B, but the public API spec also lists `llama-3.3-70b`. Confirm which are customer-available. */}

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": { "provider": "cerebras", "model": "llama3.1-8b" }
  }'
```
