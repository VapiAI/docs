OpenAI provides language models for Vapi voice agents.

You can use OpenAI through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Assistant property | Provider value |
| --- | --- | --- |
| Language model | `model.provider` | `openai` |

## Language model

Set `model.provider` to `openai` and `model.model` to a GPT model.

| Model | Model ID |
| --- | --- |
| GPT 5.6 Sol | `gpt-5.6-sol` |
| GPT 5.6 Terra | `gpt-5.6-terra` |
| GPT 5.6 Luna | `gpt-5.6-luna` |
| GPT 5.5 | `gpt-5.5` |
| GPT Instant (latest) | `chat-latest` |
| GPT 5.4 | `gpt-5.4` |
| GPT 5.4 Mini | `gpt-5.4-mini` |
| GPT 5.4 Nano | `gpt-5.4-nano` |
| GPT 5.2 | `gpt-5.2` |
| GPT 5.1 | `gpt-5.1` |
| GPT 5 | `gpt-5` |
| GPT 5 Mini | `gpt-5-mini` |
| GPT 5 Nano | `gpt-5-nano` |
| GPT 4.1 | `gpt-4.1` |
| GPT 4.1 Mini | `gpt-4.1-mini` |
| GPT 4.1 Nano | `gpt-4.1-nano` |
| GPT 4o | `gpt-4o` |
| GPT 4o Mini | `gpt-4o-mini` |
| GPT Realtime | `gpt-realtime-2025-08-28` |
| GPT Realtime Mini | `gpt-realtime-mini-2025-12-15` |
| GPT Realtime 2 | `gpt-realtime-2` |
| o3 | `o3` |
| o3 Mini | `o3-mini` |
| o4 Mini | `o4-mini` |

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": { "provider": "openai", "model": "gpt-4.1" }
  }'
```
