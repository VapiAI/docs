## What is Together AI

Together AI provides hosted inference for language models. Use the Together AI integration when you want your Vapi assistant to use a model available through your Together AI account.

## Connect Together AI

Before using Together AI, connect your account on the [Integrations](https://dashboard.vapi.ai/settings/integrations) page.

## Language model

Set `model.provider` to `together-ai`. Set `model.model` to the exact model ID from the [Together AI serverless model catalog](https://docs.together.ai/docs/serverless/models) that your connected account can access.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": {
      "provider": "together-ai",
      "model": "YOUR_TOGETHER_AI_MODEL_ID"
    }
  }'
```

For additional configuration options, review the [`TogetherAIModel` fields](/api-reference/assistants/create#request.body.model.TogetherAIModel) in the Create Assistant API reference.
