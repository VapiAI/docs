Mistral is a large language model provider whose models generate your voice agent's responses. This page covers what Mistral is and the models it supports.

## What is Mistral

Mistral builds a family of large language models. On Vapi, you select a Mistral model as the LLM for a voice agent from the dashboard.

You can use Mistral through Vapi's default integration, or use your own Mistral account by connecting it in [Integrations](/providers/integrations).

## Language model

In an assistant's model settings in the [Vapi Dashboard](https://dashboard.vapi.ai), select **Mistral** as the provider, then choose a model.

For additional API configuration options, see [Create Assistant](/api-reference/assistants/create) in the API reference.

| Model | Model ID |
| --- | --- |
| Mistral Large | `mistral-large-latest` |
| Mistral Small | `mistral-small-latest` |
