Google provides language models for Vapi voice agents.

You can use Google through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Language model | `google` |

## Language model

Set `model.provider` to `google` and `model.model` to a Gemini model.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": { "provider": "google", "model": "gemini-2.5-flash" }
  }'
```

For additional API configuration options, review the [`GoogleModel` fields](/api-reference/assistants/create#request.body.model.GoogleModel) in the Create Assistant API reference.

| Model | Model ID |
| --- | --- |
| Gemini 3.5 Flash | `gemini-3.5-flash` |
| Gemini 3.1 Flash Lite | `gemini-3.1-flash-lite` |
| Gemini 3 Flash | `gemini-3-flash-preview` |
| Gemini 2.5 Pro | `gemini-2.5-pro` |
| Gemini 2.5 Flash | `gemini-2.5-flash` |
| Gemini 2.5 Flash Lite | `gemini-2.5-flash-lite` |
