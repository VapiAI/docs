MiniMax provides language models for Vapi voice agents.

You can use MiniMax through Vapi's default integration, or connect your own account in [Integrations](/providers/integrations).

## Supported capability

| Capability | Provider value |
| --- | --- |
| Language model | `minimax` |

## Language model

Set `model.provider` to `minimax` and `model.model` to a MiniMax model.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": { "provider": "minimax", "model": "MiniMax-M2.7" }
  }'
```

For additional API configuration options, review the [`MinimaxLLMModel` fields](/api-reference/assistants/create#request.body.model.MinimaxLLMModel) in the Create Assistant API reference.

| Model | Model ID |
| --- | --- |
| MiniMax M2.7 (Beta) | `MiniMax-M2.7` |
