Inflection AI is a large language model provider whose Pi model is tuned for natural, empathetic conversation. Connect Inflection AI to use Pi as the LLM on a Vapi assistant. This page covers what Inflection AI is and the model it supports.

## What is Inflection AI

Inflection AI builds the Pi family of large language models, designed for conversational interactions. On Vapi, you select an Inflection AI model as the LLM for a voice agent.

You can use Inflection AI through Vapi's default integration, or use your own Inflection AI account by connecting it in [Integrations](/providers/integrations).

## Language model

Set `model.provider` to `inflection-ai` and `model.model` to an Inflection AI model.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": { "provider": "inflection-ai", "model": "inflection_3_pi" }
  }'
```

For additional API configuration options, review the [`InflectionAIModel` fields](/api-reference/assistants/create#request.body.model.InflectionAIModel) in the Create Assistant API reference.

| Model | Model ID |
| --- | --- |
| Pi | `inflection_3_pi` |
