xAI is a provider you can use for three parts of a Vapi voice agent: the language model (Grok), the voice (text-to-speech), and transcription (speech-to-text). This page covers what xAI is and the options each capability exposes.

## What is xAI

xAI builds the Grok family of large language models and also offers text-to-speech and speech-to-text. On Vapi, you can use xAI for any combination of the model, voice, and transcriber on a single assistant.

You can use xAI through Vapi's default integration, or use your own xAI account by connecting it in [Integrations](/providers/integrations).

## Language model

Set `model.provider` to `xai` and `model.model` to a Grok model.

| Model | Model value |
| -- | -- |
| Grok 4.3 Non Reasoning | `grok-4.3` |
| Grok 4.20 Reasoning | `grok-4.20-0309-reasoning` |
| Grok 4.20 Non Reasoning | `grok-4.20-0309-non-reasoning` |

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": { "provider": "xai", "model": "grok-4.3" }
  }'
```

## Text-to-speech

Set `voice.provider` to `xai` and `voice.voiceId` to a voice.

| Voice | Voice ID |
| -- | -- |
| Eve (default) | `eve` |
| Ara | `ara` |
| Rex | `rex` |
| Sal | `sal` |
| Leo | `leo` |

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "voice": { "provider": "xai", "voiceId": "eve" }
  }'
```

## Speech-to-text

Set `transcriber.provider` to `xai`. xAI exposes a single speech-to-text model, `default`.

```bash
curl -X PATCH "https://api.vapi.ai/assistant/ASSISTANT_ID" \
  -H "Authorization: Bearer $VAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "transcriber": { "provider": "xai", "model": "default" }
  }'
```
