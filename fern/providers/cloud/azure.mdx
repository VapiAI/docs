You can store recordings of your assistants' chat conversations in Azure Blob Storage when each conversation ends.

## What is Azure Blob Storage

Azure Blob Storage stores the recordings in a container in your storage account.

## Connect Azure Blob Storage

Container names must follow [Azure naming rules](https://learn.microsoft.com/en-us/rest/api/storageservices/naming-and-referencing-containers--blobs--and-metadata#container-names).

<Steps>
  <Step title="Find the connection string">
    Use [Azure's storage account access key instructions](https://learn.microsoft.com/en-us/azure/storage/common/storage-account-keys-manage) to find your connection string.
  </Step>
  <Step title="Open cloud provider credentials">
    In the Vapi dashboard, open **Provider Credentials** > **Cloud Providers**.
  </Step>
  <Step title="Enter the storage settings">
    Enter the connection string and container settings listed below.
  </Step>
  <Step title="Save the credential">
    Save the credential. Vapi uploads a small test file to the container to confirm the connection string and container work. If the container does not exist, Vapi creates it.
  </Step>
</Steps>

## Settings reference

Setting            | Description
------------------ | -------------------------------------------------------
Region             | The Azure region where the storage account is located
Connection String  | The connection string for your Azure storage account
Container Name     | The name of the container to upload recordings to
Path               | An optional path prefix for recordings uploaded to the container
Fallback Index     | Optional upload fallback position. Storage providers are tried in ascending order until one succeeds
