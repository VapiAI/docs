Route calls from RingCentral's contact center (RingCX) or business phone system (RingEX, formerly MVP) to your agent's number in [Vapi for CX](https://cx.vapi.ai), and hand callers back to a queue's own number. The simplest route is a RingCX Route node to the agent's number.

| | Supported |
| -- | -- |
| Receive calls | Yes, from a RingCX Route node, or a RingEX forward or menu key |
| Transfer to a phone number | Yes, to a queue's own number |
| Transfer to a SIP address | No |
| Return the call to their system | No |
| Place calls | No |

## Send calls to the agent

RingCentral sends calls to the agent's number: the free US starter number, or a number connected in Vapi for CX. Your RingCentral admin does the steps in RingCentral. Organizations in Vapi's EU region have no starter number, so connect a number of your own first: see the [overview](/phone-systems).

In Vapi for CX, open the agent and choose **Connect your phone line**, then **A contact center**. Under **Your contact center or phone system**, pick **RingCentral**, and copy the number under **Forward to**. Then follow the steps for your product, below.

### RingCX

You need RingCX admin rights for workflows.

<Steps>
  <Step title="Open the workflow">
    In the RingCentral Admin Portal, go to **Contact Center** › **Admin**, select the **RingCX Admin** tile, then **Categorization** › **Workflows**. Open the workflow, then **Workflow Studio**. For more information, see RingCentral's [Route node](https://support.ringcentral.com/article-v2/Using-the-Route-node-in-the-RingCX-IVR-Studio.html).
  </Step>
  <Step title="Add a Route node to the agent's number">
    Add a **Route** node, set **Type** to PSTN and enter the agent's number in **Destination**. Set **Caller ID** to ANI (the caller's own number) and set **Ring Duration**. Leave **TT Accept** off: it makes the answerer press a key, and with no key the call counts as unanswered. Save.
  </Step>
</Steps>

**The number the agent sees** on RingCX is the caller's own number, with **Caller ID** set to ANI.

### RingEX

Forward one user's calls, or add a phone menu (IVR) key.

- **Forward a user's calls:** in RingEX, select the user's profile picture, then **Call rules** › **Forward all calls**. For incoming calls, choose **Forward the call** › **Number**, enter the agent's number, optionally **Add schedule**, and save. You can do the same for an extension in the Admin Portal. For more information, see RingCentral's [forwarding calls](https://support.ringcentral.com/article-v2/Forwarding-calls-external-number.html).
- **Add a menu key:** in the Admin Portal, go to **Phone System** › **Company** › **IVR Menus**, select the IVR, then **Key Presses** › **Add Key**. Pick the key, set **Action** to **External Transfer** with the agent's number in **Transfer to**, and save. Menus built in the IVR Visual Editor or the XML editor can't be edited here. For more information, see RingCentral's [IVR menus](https://support.ringcentral.com/article-v2/Create-New-IVR-Menu-RingCentral.html?brand=RingCentral&product=RingEX&language=en_US).

On RingEX, RingCentral treats the forward as a new call, so the agent may see your company number rather than the caller's.

### Check the line

In Vapi for CX, choose **Check the line**, then call your RingCentral number from your own phone. The check passes when your call reaches the agent. On RingEX, if a "press 1 to accept" prompt plays, route from a menu key instead: the agent can't press keys. Then choose **Next: add a handoff**.

## Hand callers to your team

The agent transfers the caller to a number that rings a queue. For how handoffs work, see [Handing callers to people](/phone-systems#handing-callers-to-people).

<Steps>
  <Step title="Get a number that rings the queue">
    Do one of these:

    - **RingEX call queue:** in the Admin Portal, go to **Phone System** › **Groups** › **Call Queues**, select the queue, then **Direct Numbers** › **Add Direct Number**. Choose the location, number type, state and area code, pick a number, then **Add Numbers**, **Next**, accept the acknowledgement, **Next** and **Done**. For more information, see RingCentral's [create a call queue](https://support.ringcentral.com/article-v2/Create-Call-Queue.html?brand=RC_US&product=RingEX&language=en_US).
    - **RingEX IVR menu:** go to **Phone System** › **IVR Menus**, and in Actions choose the More icon (...) › **Add number**. Choose the location and number type, pick a number, then **Add Numbers**, **Next**, confirm and **Done**. For more information, see RingCentral's [add a direct number to an IVR menu](https://support.ringcentral.com/article-v2/Add-Direct-Number-IVR-Menu-RingCentral.html?brand=RC_US&product=RingEX&language=en_US).
    - **RingCX:** in Workflow Studio, set up a second number whose workflow has a **Route** node with Type **Voice queue**.

    Don't use the number that forwards to the agent.
  </Step>
  <Step title="Add the handoff">
    In Vapi for CX, on the agent's **Call handling** tab, choose **Add a handoff** on the **Handing callers to people** card. Say when the agent should use it, choose **Transfer to a phone number**, and enter the queue's, menu's or workflow's number. For more information, see [Transfer calls](/tools/transfer-call).
  </Step>
</Steps>

**The number your people see** is the caller's own number when the agent's line is a Twilio number connected in Vapi for CX. On the starter number, it's the agent's number unless the handoff shows the caller's number, and the carrier may refuse a number the line doesn't own.

**Check it:** once the handoff is live, choose **Check** on its row, call the agent from your phone and ask for a person. The check shows **Handoff sent** when the agent hands you over.

## Limitations

- RingEX menus, queues and call rules take phone numbers only, so RingCentral can't route to a SIP address.
- No summary or caller details travel with a handoff.
- When the agent hangs up, the call ends: neither a RingEX forward nor a RingCX Route node to a phone number takes the caller back.
- Each call to the agent is two calls for its whole length, and a handoff adds a third. RingCentral may charge for forwarded minutes, and Vapi bills its minutes on top.
- RingCentral gives third parties no outbound connection, so the agent places calls from its own line.

## Other options

<Accordion title="Other ways to connect RingCentral">

- **RingEX call queue "Forward to External number":** a queue can send callers to the agent's number when the queue is full, the maximum wait is reached or no member answers. Check your Admin Portal to see whether your plan includes it. If a "press 1" prompt plays, use a menu key instead.
- **RingCX IVA Integrations** (RingCentral's route for an outside voice agent over SIP): not available. Use a RingCX Route node to the agent's number instead.
- **Registering the agent as a RingEX SIP desk phone:** not recommended.
- **Your own carrier (BYOC) or Cloud Connector:** not a route to the agent. BYOC is sales-led through a gateway you own, and Cloud Connector is a migration link.

</Accordion>
