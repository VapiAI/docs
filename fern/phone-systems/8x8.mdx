Point an 8x8 Contact Center script step, or an 8x8 Work Auto Attendant, at your agent's number in [Vapi for CX](https://cx.vapi.ai). On 8x8 Contact Center, 8x8's [External IVR API](https://help.8x8.com/docs/8x8-contact-center-external-ivr-api) documentation describes the script carrying on at its **Resume** exit when the outside party hangs up, so the caller can go back to your queue on the original call.

- **Receive calls:** Yes, from a Contact Center script or an 8x8 Work Auto Attendant.
- **Transfer to a phone number:** Yes, to an 8x8 number.
- **Transfer to a SIP address:** No: 8x8 gives you no SIP address to send callers to. Use **Transfer to a phone number**.
- **Return the call to their system:** On 8x8 Contact Center, through the script's **Resume** exit, as 8x8's documentation describes it.
- **Place calls:** No.

## Send calls to the agent

8x8 sends calls to the agent's number: the free US starter number, or a number connected in Vapi for CX. Your 8x8 admin does the steps in 8x8. Organizations in Vapi's EU region have no starter number, so connect a number of your own first: see the [overview](/phone-systems).

In Vapi for CX, open the agent and choose **Connect your phone line**, then **A contact center**. Under **Your contact center or phone system**, pick **8x8**, and copy the number under **Forward to**. For Contact Center, drop the `+`: the field takes digits only, with the country code (in the US, `14155550124`). Then follow the steps for your product, below.

### 8x8 Contact Center

Use the script object **Forward to External IVR**, not **Forward to External Number**: Forward to External Number has no exits, so the call never comes back to the script.

<Steps>
  <Step title="Open the channel's script">
    In 8x8 Configuration Manager, go to **Channels** › Phone tab, select the channel, then **Properties**, and note which script the channel uses. 8x8 assigns a default one if none is picked. Then go to **Scripts** › Phone tab and **Edit** that script.
  </Step>
  <Step title="Add Forward to External IVR">
    In the script, add **Forward to External IVR**. Give it a label (letters and digits, up to 21 characters, unique in the script), and enter the agent's number, digits only, as the access phone number. Save the script. For more information, see 8x8's [External IVR API](https://help.8x8.com/docs/8x8-contact-center-external-ivr-api).
  </Step>
</Steps>

### 8x8 Work

In the 8x8 Admin Console, go to **Auto Attendants**, choose **Edit**, then **Call Handling Menus** › **Main Menu** › **Edit Settings**. Set "And then," to **Route call to**, enter the agent's number as the Target with `+` or `00` and the country code, and save. For more information, see 8x8's [forward Ring Group and Auto Attendant calls](https://help.8x8.com/docs/how-do-i-forward-ring-group-and-auto-attendant-calls-to-an-external-number).

### Check the line

In Vapi for CX, choose **Check the line**, then call your 8x8 number from your own phone. The check passes when your call reaches the agent. Then choose **Next: add a handoff**.

## Hand callers to your team

On 8x8 Contact Center, return the call to the script. On 8x8 Work, transfer to an 8x8 number. For how handoffs work, see [Handing callers to people](/phone-systems#handing-callers-to-people).

### Return the call to their system

8x8's [External IVR API](https://help.8x8.com/docs/8x8-contact-center-external-ivr-api) documentation describes a **Forward to External IVR** object whose script carries on at its **Resume** exit when the outside party hangs up. Set up that way, the caller stays on the original call, so your person sees the real caller, 8x8's reporting stays whole, and there's no extra call.

<Steps>
  <Step title="Add Forward to Queue under Resume">
    In 8x8 Configuration Manager, on the same **Forward to External IVR** object, add **Forward to Queue** under its **Resume** exit, with the queue name. Optionally put a Test Variable object before it. Save. For more information, see 8x8's [Data Augmentation](https://docs-alt.8x8.com/8x8WebHelp/VCC/configuration-manager-vovcc/content/data-augmentation.htm).
  </Step>
  <Step title="Decide what Resume does with every call">
    8x8 describes Resume as running whenever the outside party hangs up, or when 8x8 can't connect to the number. Nothing tells 8x8 why, so every call the agent ends takes that path, including calls where the caller had finished. Either have the agent end the call only when a person is needed, or have Resume play a short menu such as "press 1 for a person". If the caller hangs up, the call simply ends.
  </Step>
  <Step title="Add the handoff">
    In Vapi for CX, on the agent's **Call handling** tab, choose **Add a handoff** on the **Handing callers to people** card. Say when the agent should use it and choose **Return the call to their system**. This type is offered once 8x8 is linked to the agent's line, which picking 8x8 on the contact-center screen does.
  </Step>
</Steps>

### Transfer to an 8x8 number

The agent transfers the caller to a new 8x8 number, which adds a third call. On 8x8 Work, use the number of an Auto Attendant, Ring Group, Call Queue or user. On Contact Center, set up a second number whose script goes straight to a queue:

<Steps>
  <Step title="Make a second number a Contact Center channel">
    In the 8x8 Admin Console (apps.8x8.com), go to **8x8 Contact Center** › **Channels**, search for the number, select it, and choose **Assign to Contact Center**. A green banner confirms it. Multi-tenant accounts follow 8x8's "Setting Up 8x8 Contact Center Service Channels" instead. For more information, see 8x8's [assign numbers to Contact Center](https://help.8x8.com/docs/assign-or-unassign-numbers-from-8x8-contact-center).
  </Step>
  <Step title="Give that channel a script that queues">
    In 8x8 Configuration Manager, make a script that goes straight to **Forward to Queue**, and pick the queue. Then go to **Channels** › Phone tab, select the channel, then **Properties**, pick that script and save. For more information, see 8x8's [assign a script to a channel](https://docs-alt.8x8.com/8x8WebHelp/VCC/configuration-manager-general/content/scriptsassignedchannel.htm).
  </Step>
  <Step title="Add the handoff">
    In Vapi for CX, on the agent's **Call handling** tab, choose **Add a handoff** on the **Handing callers to people** card. Say when the agent should use it, choose **Transfer to a phone number**, and enter the 8x8 number. Don't use the number that forwards to the agent. For more information, see [Transfer calls](/tools/transfer-call).
  </Step>
</Steps>

**The number your people see** after a transfer is the caller's own number when the agent's line is a Twilio number connected in Vapi for CX. On the starter number, it's the agent's number unless the handoff shows the caller's number.

**Check it:** once the handoff is live, choose **Check** on its row, call the agent from your phone and ask for a person. The check shows **Handoff sent** when the agent hands you over.

## Limitations

- No SIP address can be entered anywhere in 8x8, so 8x8 can't route to one.
- No summary or caller details travel with a handoff: 8x8 identifies a call only by its own call ID, and a new call into 8x8 gets a new one.
- Nothing tells the script why the agent hung up: every call the agent ends lands at Resume.
- On 8x8 Work, when the agent hangs up, the call ends: use a transfer to an 8x8 number instead.
- Each call to the agent is two calls for its whole length. Ask your 8x8 account team whether forwarding to outside numbers is charged on your plan. Vapi bills its minutes on top.
- 8x8 Contact Center numbers take incoming calls only, so the agent places calls from its own line.
